# Roteiro de Aprendizado e Descobertas: Exercício 2 (Filtro de Dados - Map)

## Especificação de Requisitos (Extraída do Java)

* Entrada: 5.000 strings (nomes de usuários) lidas de um arquivo TXT.
* Particionamento: Dividir a lista em 2 blocos (2.500 nomes cada).
* Processamento: 2 tarefas concorrentes aplicam regras de limpeza:
  1. Removem espaços em branco do início e do fim (`Trim`).
  2. Convertem o texto para letras maiúsculas (`ToUpper`).
* Agregação: Cada tarefa retorna uma nova lista limpa. A thread principal junta as listas resultantes.

## Comparação: Versão Didática vs Versão Idiomática em C#

### Versão Didática (Loop Tradicional) - Aplicada na Task
```csharp
List<string> nomesLimpos = new(_nomes.Count);
foreach (string nome in _nomes)
{
    nomesLimpos.Add(nome.Trim().ToUpperInvariant());
}
return nomesLimpos;
```

### Versão Idiomática (LINQ Select) - Alternativa Equivalente
```csharp
return _nomes.Select(nome => nome.Trim().ToUpperInvariant()).ToList();
```

## Agregação de Listas Retornadas pelas Tarefas (SelectMany)

No Java, usava-se `resultadoFinal.addAll(futuro.get())` dentro de um loop.
Em C#, ao aguardar `await Task.WhenAll(tarefas)`, obtemos um array de listas: `List<string>[] resultados`.

Para achatar (flatten) esse array de listas em uma única lista final de forma funcional e performática, utilizamos o método de extensão LINQ `SelectMany`:
```csharp
List<string> resultadoFinal = resultadosDasPartes.SelectMany(r => r).ToList();
```
Essa descoberta demonstra a elegância da programação funcional integrada no C#.
